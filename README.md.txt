
# CampusFind

Plateforme universitaire de recherche d'espaces,
de réservation et de collaboration étudiante.

## Architecture
- Microservices Spring Boot
- API Gateway
- Eureka Discovery
- Config Server
- Keycloak
- Docker Compose

## Microservices
1. Study Space Service
2. User Management Service
3. Student Expression Service
4. Room Reservation Service
5. Study Community Service
6. Campus Issues Service

## Service commun
Notification & Messaging Service

## Organisation
- Backend : microservices
- Frontend : application Web
- Documentation : diagrammes et présentation
